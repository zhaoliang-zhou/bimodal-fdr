# General Framework for Enhancing Power in Empirical-Bayes Multiple Testing with Auxiliary Information

This repository contains the R code used to reproduce the theoretical figures and reported numerical summaries in the "General Framework for Enhancing Power in Empirical-Bayes Multiple Testing with Auxiliary Information". 
The restricted LLD neuroimaging data are not included because they cannot be publicly distributed; the public workflow therefore uses the manuscript’s reported parameter estimates and summary results rather than re-estimating the analysis from individual-level data.
